Как читать цифры

  • GitHub считает каждое скачивание файла из выпуска. Это не уникальные люди: один человек может скачать файл дважды.
  • Windows .exe скачивают и люди, и автообновление Ulov. Файл .blockmap берёт только автообновление, поэтому «новые установки ≈ exe минус blockmap» это грубая оценка, а не точное число.
  • Mac .dmg скачивают только руками, так что это почти чистые установки и ручные обновления.
  • Проверки обновлений показывают, как часто запущенные копии Ulov спрашивают про новую версию. Растут вместе с числом активных пользователей.
  • Служебные файлы (SHA256SUMS, .zip для Mac) в подсчёт не входят. Старые сборки Sona из приватного репозитория тоже не входят: их мог скачать только владелец.
